A program that writes one Wi-Fi network name of at most 32 characters — the funniest name that hints at a whole story. It scores a pool of candidate names against the judge's published brief — joke first, then how much story the name carries, then freshness and tight wording — and writes the winner, **Ex Changed Password, Still Texts**, to `/output/entry.txt`. The breakup in one line: an ex who locked you out of the Wi-Fi but still texts you — a character, a situation, and an event, with the contradiction as the punchline.

## Run it

```sh
python3 main.py
```
